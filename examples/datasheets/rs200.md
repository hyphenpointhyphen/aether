# RS-200 Wireless Room Sensor — Modbus Register Map

Firmware 2.3. Unit ID 1. All values are holding registers (function code 03).

| Register | Name             | Description                     | Type   | Scale | Unit | Access | Range     |
|----------|------------------|---------------------------------|--------|-------|------|--------|-----------|
| 0        | ROOM_TEMP        | Room air temperature            | int16  | 1     | °C   | R      | -10..50   |
| 1        | ROOM_RH          | Room relative humidity          | uint16 | 0.1   | %    | R      | 0..100    |
| 2        | BATT             | Battery level                   | uint16 | 1     | %    | R      | 0..100    |

Note: values are updated every 10 s.
